## Как я работаю

```text
процесс AS-IS  →  метрики и источники  →  витрина в SQL
                                              ↓
регламент / решение  ←  дашборд или таблица для бизнеса
```

1. Понять, какое решение должен принять руководитель.
2. Найти, где сейчас живут данные и где теряется время.
3. Собрать витрину, которую можно переиспользовать.
4. Отдать результат в том виде, которым реально пользуются: дашборд, таблица, расчёт.
5. Проверить цифры и оставить короткие выводы, а не только графики.
