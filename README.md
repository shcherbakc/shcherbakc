## Практика: оцифровка маркетплейсов

```mermaid
flowchart LR
    A[WB · Ozon · Маркет · МойСклад] -->|API| B[Google Apps Script]
    B -->|по расписанию| C[(PostgreSQL)]
    C --> D[Yandex DataLens]
    C --> E[Google Таблица]
    D --> F[Решение бизнеса]
    E --> F
```

Снимаю процесс AS-IS, забираю данные из кабинета или учёта, собираю витрину и отдаю дашборд или таблицу, которой пользуются.
